# 🚀 Jhon E. Martinez — AI Portfolio

Portfolio web interativo apresentando **124 projetos de IA de vanguarda**: RAG, LLMs, Multi-Agents, MLOps, Computer Vision, NLP e muito mais.

🔗 **Live:** https://jhondados.github.io/portfolio

## ✨ Features

- 🎨 **Design de última geração** — UI/UX elegante com Tailwind CSS
- 🌗 **Modo claro/escuro** — alternância suave com alto contraste
- ⚡ **Demos interativas ao vivo** — cada categoria de projeto tem uma demo funcional:
  - **RAG**: pipeline de recuperação + geração ao vivo
  - **Agents**: orquestração multi-agente sequencial
  - **ML**: scoring de churn com sliders em tempo real
  - **NLP**: análise de sentimento e entidades em PT-BR
  - **Vision**: detecção de objetos com bounding boxes animados
  - **Pipeline**: fluxo de dados streaming visual
  - **Security**: feed de ameaças em tempo real
  - **Chart**: forecasting com bandas de confiança
  - **Chat**: assistente jurídico AI interativo
- 🔍 **Busca + filtros** por nome, tecnologia e categoria
- 📱 **100% responsivo** — mobile, tablet e desktop
- ⚛️ **React 18** + Tailwind CSS (zero build, single-file)

## 🛠 Stack

`React 18` · `Tailwind CSS` · `Canvas API` · `HTML5` · `CSS3` · `JavaScript ES6+`

## 🏃 Rodar localmente

```bash
python -m http.server 8765
# abra http://localhost:8765
```
